# Reference atlas — computational editorial art

This atlas is a research instrument for the artwork lane, not a mood-board or a list of styles
to imitate. Open only the sources relevant to the day's visual problem. For every selected
reference, record:

1. the precise craft property being studied;
2. the story evidence it could help express;
3. the transformation that makes the result specific to this record;
4. what must not be copied.

Prefer primary sources, original project pages and technical documentation. Do not download or
embed copyrighted reference imagery in the repository. Public-domain archival material still
needs source and rights notes in the day's dossier.

## Reference-set recipe for one deck

Use **three to six references**, enough to triangulate and few enough to influence decisions:

- one story-domain source: the actual place, material, machine, institution or record;
- one composition/camera source;
- one light/material or mark-making source;
- one data/scientific source when geometry carries evidence;
- optionally one sequencing or LinkedIn-native source.

At least two references must come from outside the current AI-design aesthetic. At least one
must be a primary story-domain source. If all references look alike, the set is permission to
imitate, not research.

Use this note shape in the day's visual research artifact:

```text
REFERENCE
URL / item ID:
Study only:
Story evidence it serves:
Transform into:
Do not copy:
Rights / provenance:
```

The final image should make the references difficult to reverse-engineer. What remains visible
is the Docket's judgment about this particular record.
