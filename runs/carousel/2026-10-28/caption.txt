Cameras ride 50 Dallas brush trucks.

The trucks keep the routes they already run. The software is City Detect. It flags possible exterior property and right-of-way conditions along the way.

The city's October 19th briefing says an observation is not a confirmed Code violation. It says trained staff review every one before Code Compliance acts. In a prioritized inspection a Code Inspector goes on site to find out whether a violation exists.

The first letter a resident got used to be a formal notice of violation. The briefing says a first courtesy letter is now an educational reminder with no deadline.

The October 19th briefing publishes no accuracy figure. It lists calibrating detection accuracy and setting accuracy measures as next steps. How accurate was the camera across the 5,318 observations reviewed?
