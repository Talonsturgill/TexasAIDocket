# The comptroller proposes a rule treating cloud computing and AI as hosted services outside the sales tax on data processing

The Texas Comptroller proposed amendments to Rule 3.308 on November 18th. They would define a taxable data processing service as processing data a customer supplies and returning the data organized. Internet hosting, cloud computing and artificial intelligence would count as hosted technology services. They would not be taxed as data processing. It is a proposal and not yet adopted. It appeared in the Texas Register on November 20th. The comptroller's own estimate puts the loss to the state's General Revenue Fund at $1,947,310,000 in fiscal year 2027. It reaches $4,286,040,000 in fiscal year 2032. Local governments would lose $507,450,000 in the first year.
