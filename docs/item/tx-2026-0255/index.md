# The comptroller proposes a rule treating cloud computing and AI as hosted services outside the sales tax on data processing

The Texas Comptroller proposed amendments to Rule 3.308 on November 18th. They would define a taxable data processing service as processing data a customer supplies and returning the data organized. Internet hosting, cloud computing and artificial intelligence would count as hosted technology services and not be taxed as data processing. It is a proposal and not yet adopted. It is to be published in the Texas Register, which carries the comment instructions.
