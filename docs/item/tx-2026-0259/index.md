# Texas Tech opens a telecom security testbed at the Reese complex in Lubbock, where a Nokia AI sensing system tracked drones

Texas Tech opened the Critical Infrastructure Telecom Ecosystem Incubator at its Reese National Security Complex on November 10th. It pairs university researchers with AT&T and Nokia Federal Solutions. The Texas University Fund supports it. At the opening, Nokia's sensing system tracked drones flying faster than 60 mph. That system uses AI. The work is a demonstration and names no deployment yet.
