# Volvo and Waabi start hauling a customer's freight between Dallas and Houston on autonomous trucks, with an observer in the driver's seat

Volvo Autonomous Solutions and Waabi announced on October 5th the start of autonomous operations for Warp, a freight network, in Texas. Volvo trucks running Waabi's driving system now carry freight to third party facilities along the Dallas to Houston corridor. It is the first customer operation of the two companies' partnership. The release says the hauls run with an observer in the driver's seat. It reports no truck count or mileage.
