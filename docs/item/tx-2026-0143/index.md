# ERCOT starts sending the Batch Zero questionnaires, and a data center that does not answer comes off the list

ERCOT issued a market notice on September 9th, 2026. It states that the grid operator has begun sending Batch Zero Verification Requests for Information. They go to a majority of the large load entities whose loads were conditionally included in Batch Zero. The notice states that completing the verification is a condition of staying in Batch Zero. Batch Zero is the group of large loads whose place in the interconnection study was frozen pending the audit the Governor directed in August.

### The grid operator states it has begun issuing the verification requests.

> In accordance with this directive, ERCOT has begun issuing Batch Zero Verification Requests for Information (RFIs) to a majority of Interconnecting Large Load Entities (ILLEs) with a Large Load that has been conditionally included in Batch Zero.

> Successful completion of the verification process is a condition for the Large Load's inclusion in Batch Zero.
