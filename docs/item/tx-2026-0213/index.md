# UT San Antonio builds a free training platform where students learn to find the security flaws in code an AI wrote

The National Science Foundation funds a UT San Antonio project led by Nishant Vishwamitra of the College of AI, Cyber and Computing. Its platform, OpenSecCoder, will teach students to work with code an AI tool generated and to find and fix its security problems in a sandbox. Each lab gives a student a coding agent, a terminal and a debugger. The release says most of the labs need no programming background. It projects how many students a year the project will reach, together with the University at Buffalo. The platform and labs are still being built and no result is reported.
