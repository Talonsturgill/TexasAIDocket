Texas Grid Watch

What large load has asked the Texas grid for, and what it is actually drawing. Most of that queue is data centers, and this page names the ones the state has registered. Measured, never predicted.

The Queue Gap

Large load has asked ERCOT for 410 GW. 4.4 GW of it is drawing power.

Asked for 410 GW
Drawing power 4.4 GW

87% of the queue is data centers. Queue read March 26th, 2026. The rest read July 2026. Both from ERCOT.
