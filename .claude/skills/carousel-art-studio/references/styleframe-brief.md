# Styleframe competition brief

Create this artifact before full-deck production.

## Shared truth

```text
Article / date:
Cover claim:
Interior-turn claim:
Known visual evidence:
Forbidden implications:
Recent constructions to avoid:
```

## Reference cut

Three to six entries, each with URL/item ID, study-only property, story evidence served,
transformation, do-not-copy note and rights/provenance.

## Candidate card — repeat at least three times

```text
NAME — a concrete noun/verb phrase, not an adjective

Visual thesis:
Memory sentence:
Literal anchor:
Evidence behavior / metaphor boundary:

Image architecture:
Camera / lens / horizon:
Near-middle-far planes:
Key / fill / practical light:
Hero material and contrast material:
Type's spatial role:
Generative or motion rule:

Cover shot:
Interior-turn shot:
Why it cannot belong to another story:
Which current AI-design default it rejects:
Hardest technical proof:
```

Build both shots. Use shared copy across candidates so copy quality does not bias the visual
choice. Candidate directions must not share image architecture, camera grammar and material
world.

## Render board

For every candidate include:

- 1080×1350 cover;
- 432-pixel cover thumbnail;
- 1080×1350 interior turn;
- 432-pixel interior thumbnail;
- grayscale thumbnails;
- notes on what survived or disappeared.

Do not compare browser screenshots at arbitrary zoom. Use engine output and actual thumbnails.
