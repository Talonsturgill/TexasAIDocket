# Code atelier — reading finished constructions

`examples/art-atelier/` is a set of executable visual studies made with the same offline assets
as production. Each frame isolates a larger construction — shot, camera, light, material,
evidence and type — rather than advertising a primitive.

## How to use it

1. Choose the construction whose **problem** resembles the story's, not the one whose look you
   like most.
2. Render it through `carousel-engine`; do not judge source code names or a browser at arbitrary
   zoom.
3. Inspect the full render and 432-pixel thumbnail.
4. Read how macro composition is separated from micro detail.
5. Extract a mechanism: depth ordering, highlight construction, type reserve, data-to-form
   mapping, evidence integration.
6. Rebuild the mechanism with the day's own nouns, camera, palette, material and behavior.

Never duplicate an atelier frame and replace its text. That would turn a craft reference into
the template this skill exists to prevent.

## Construction index

| Frame | Problem it demonstrates | Inspect for |
|---|---|---|
| 01 — evidence monolith | Make a record feel physical and consequential | Extreme crop, lit edge, embedded evidence, type as counterforce |
| 02 — volumetric cutaway | Reveal concealed layers/process without a dashboard | Impossible evidence camera, depth separation, motivated internal light |
| 03 — topographic signal | Turn a verified gradient or threshold into a material field | Macro density transition, contour survival, one literal anchor |
| 04 — data sculpture | Give a small verified series scale and spatial presence | Bound geometry, camera, lit ground, quantitative legend discipline |
| 05 — document archaeology | Use real record matter without making a paper collage | Layered depth, raking light, selective focus, exact fragment provenance |
| 06 — typographic machine | Let language participate in physical behavior | Type as structure, moving parts, legibility protected by construction |

These frames are technique-agnostic at the concept level. Production may implement the same
construction with Canvas, SVG, relief, SDF or Three.js depending on the shot budget.

## What to copy and what not to copy

Copy:

- explicit value hierarchy;
- camera and depth planning;
- motivated light;
- material differentiation;
- a macro read plus micro reward;
- deterministic mechanics;
- protected vector type;
- comments explaining visual decisions.

Do not copy:

- palette;
- type lockup;
- object silhouette;
- exact shader/noise parameters;
- frame layout;
- story metaphor.

The atelier is successful when tomorrow's work looks nothing like it but is built with the same
degree of intention.
