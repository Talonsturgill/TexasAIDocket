# Computational systems — behavior with meaning

## Pick a behavior, not an effect

Describe the system as a sentence:

> **[entities]** move/grow/partition/accumulate according to **[rule]**; **[verified input]**
> controls **[visible property]**; the viewer should perceive **[claim]**.

Examples of meaningful mappings:

- delay controls queue length, not arbitrary hue;
- uncertainty controls blur or boundary instability, not fake precision;
- load controls density or deformation when the scale is documented;
- jurisdiction controls real polygon membership, not invented cells;
- time controls position or erosion along one declared direction.

If there is no verified input, label the system illustrative and make no legend that suggests
measurement.

## System families

| Behavior | Good for | Common lie/failure |
|---|---|---|
| Advection / flow | movement, transmission, drift | random streamlines imply routes or volume |
| Accumulation | queue, backlog, compounding | area looks quantitative without a scale |
| Field / contour | threshold, gradient, influence | decorative noise masquerades as measured terrain |
| Packing / collision | capacity, congestion, constraint | circle size implies magnitude accidentally |
| Growth / branching | propagation, dependency, buildout | invented topology reads as a real network |
| Partition | allocation, territory, ownership | Voronoi cells replace real jurisdictions |
| Erosion / fracture | loss, stress, exposure | damage metaphor overstates an administrative change |
| Oscillation / wave | cycles, instability, signal | amplitude or frequency appears data-bound when it is not |

## Authored generative work

Randomness is not art direction. Define:

- invariant structure — what every seed must preserve;
- bounded variation — which properties may move and within what range;
- composition constraints — quiet zone, dominant mass, collision rules;
- selection policy — whether a seed is fixed before or after styleframe review;
- failure detection — empty field, even density, hair-like lines, moiré, bad crop.

Use deterministic seeds. Never sample seeds until one “looks cool” without recording the
selection, because that hides art direction inside roulette.

## Data, model and metaphor labels

Classify every visual layer:

- **DATA** — directly bound to a cited value;
- **MODEL** — produced by a documented transformation or simulation;
- **MAP** — real geographic geometry/projection;
- **ILLUSTRATION** — explanatory but not measurable;
- **ATMOSPHERE** — non-semantic finish.

The dossier should say which is which. Data may drive illustration, but the reader must not be
invited to recover a number the mapping cannot support.

## Thumbnail stability

Generative detail dies first at 432 pixels. Design two scales:

- macro structure: one silhouette, density transition or directional field;
- micro reward: marks, particles, hachure, interference or grain.

If removing the micro layer erases the claim, the system is under-composed. Avoid line spacing
and repetition frequencies that moiré after downsampling; render the actual thumbnail.
